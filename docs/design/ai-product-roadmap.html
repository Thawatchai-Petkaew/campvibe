! Risks / constraints

availability ต้องแม่นก่อน AI — PREP-1 ต้องเสร็จก่อน A3/A4 ไม่งั้นแชทตอบ "ว่าง" ผิด → double-booking
วิดีโอ harvested (F2/VID-3) ยังขัด ToS TikTok/FB เชิงเทคนิค + thumbnail ลิขสิทธิ์ครีเอเตอร์ · ลดเสี่ยง: allow-list + link-out ไม่ rehost + เครดิต/ลิงก์กลับ + takedown + batch ถี่ต่ำ (owner รับความเสี่ยงแล้ว) · กลไก scrape (self-host vs 3rd-party=spend) เคาะที่ G2
embeddings deferred (ADR-009) — v1 ใช้ tool-use/keyword; query แนว "ฟีลดิบ เงียบ" อาจอ่อนจนกว่าจะเติม vector (content-only)
external API + spend — D3 weather, E1 POI, D1 maps/routing, H1–H3 generation, F2 scraper = มีค่าใช้จ่าย ต้องอนุมัติ G2
CSP — ฝัง owned video (F3/VID-2) ต้องเพิ่ม frame-src/script-src โดเมน player ใน proxy.ts
